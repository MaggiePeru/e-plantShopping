# Paradise Nursery - E-Plant Shopping Application

An e-commerce web application built with React and Redux Toolkit for selecting, managing, and purchasing indoor plants.

## Features
- **Product Catalog:** Browse various plant categories and add items to the cart.
- **State Management:** Fully powered by Redux (CartSlice) to track quantities and items globally in real time.
- **Shopping Cart:** Dynamic calculations of item quantities, subtotals, and total order amounts.
- **Responsive UI:** Styled layout with instant visual feedback upon interactions.
